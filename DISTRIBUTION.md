# Distribution

1. Push to GitHub.
2. Enable GitHub Pages with **GitHub Actions**.
3. Verify the live URL.
4. Update the canonical URL and sitemap if the final URL differs.
5. Verify the site in Google Search Console and submit `sitemap.xml`.
6. Verify the site in Bing Webmaster Tools, submit the sitemap, and enable IndexNow.

Search engines control crawling and indexing; submissions and IndexNow notifications do not guarantee search placement or indexing.

The `extension/` folder is a Manifest V3 Chromium new-tab build for local testing and later store submission.
