# MergeFrenzy

Free, static 2048-style merge puzzle game.

## GitHub Pages
Enable **Settings → Pages → Source → GitHub Actions**. The repository includes an automated Pages workflow.

## Local
```bash
python3 -m http.server 8000
```

## Cost
No backend, database, paid API, or build system is required.

See `MONETIZATION.md`. The repository does not include fake advertisements or invented sponsored brands.
